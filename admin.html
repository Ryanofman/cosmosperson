Gallery Admin

Sign in with a GitHub access token to manage the gallery — pick which photos show up, reorder them, edit their details, and publish straight to the live site.

How to create a token
  1. Open GitHub → Settings → Developer settings → Fine-grained tokens.
  2. Under Repository access, choose Only select repositories and pick this repository.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Generate the token and paste it above. It stays on this device only.
